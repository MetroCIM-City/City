# campus Albano

Babylon.js recreation of the [Campus Albano 3D viewer](https://campusalbano.se/view/all).

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5176/

After `npm install`, the viewer runs fully offline. Fonts, icons, 3D models, and the Draco decoder live under `public/assets/`.

## Controls

- Left drag: pan
- Right drag: rotate
- Scroll: zoom
- Sidebar: expand categories, toggle marker visibility, open articles
